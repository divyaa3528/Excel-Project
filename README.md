# Excel-Project
Vrinda Store Sales Report Dashboard
Vrinda Annual Sales Report 2022 | Excel

Tools: Excel, Pivot Tables, Pivot Charts

Developed an Excel dashboard to analyze monthly sales, order status, customer demographics, and sales channels.

Used Pivot Tables, Pivot Charts, and slicers for dynamic filtering and interactive analysis.

Identified key insights, including 64% female customer contribution, Amazon as the top-performing channel, and Maharashtra as the highest-revenue state.
